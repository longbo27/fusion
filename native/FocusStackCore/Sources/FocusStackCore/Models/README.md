FocusMotionNetProto.mlpackage is a compact synthetic-only motion/blend-safety mask prototype shared by macOS, iOS and iPadOS. It is not a production model. Training provenance and measured quality/placement are recorded in the adjacent metadata and native/Docs/ML_PROTOTYPE.md. RGB pixels are never model output. AI defaults Off. Production models require photographic, numerical, memory and device validation. Compiled mlmodelc/mtlpackage and training checkpoints remain outside Git.
